# 🎙️ Voice Generator — Online (Streamlit version)

Realistic Microsoft neural voices, **unlimited, no credits, no API key**.
Runs in your browser. Free hosting on Streamlit Community Cloud.

- **8 voices:** Urdu (Asad/Uzma), Hindi (Swara/Madhur), English US + India
- **7 style presets:** Normal, Happy, Excited, Sad, Angry, Calm, Suspenseful
  (honest note: these are speed+pitch presets, not true acted emotions)
- MP3 download button

## Deploy (free, ~5 minutes)

1. GitHub par free account banao (github.com) — agar nahi hai
2. New repository banao, naam `voice-generator`
3. Is folder ki dono files (`app.py`, `requirements.txt`) repo mein upload karo
4. **share.streamlit.io** kholo → GitHub se sign in → **"New app"**
5. Repository + branch + `app.py` select karo → **Deploy**
6. 2-3 minute mein tumhara link taiyaar: `tumhara-naam-voice-generator.streamlit.app` 🔖

**2 chhoti baatein:** free apps 12 ghante idle rehne par so jati hain (link kholo to khud jaag jati hai, ~30 sec), aur pehli Generate mein 10-20 second lag sakta hai.
